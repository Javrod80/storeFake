# 🛒 StoreFake

**StoreFake** es una aplicación web que permite a los usuarios explorar productos de una API externa, agregarlos a un carrito de compras y simular una compra.

## 📌 Características
- 🔍 Consulta de productos desde una API externa.
- 🛒 Agregar y eliminar productos del carrito.
- 🛍 Simulación de compra.
- 👤 Gestión de sesión de usuario.
- 🛠 Actualización y eliminación de productos.

## 🛠 Tecnologías utilizadas
- **HTML**: Estructura de la aplicación.
- **CSS**: Estilos para mejorar la presentación.
- **JavaScript**: Manipulación del DOM y consumo de API externa.
